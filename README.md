# TestProject

GitHub 연동 및 코드 푸시 테스트를 위한 **간단한 할 일 관리 웹 페이지**입니다.

## 실행 방법

별도의 서버나 의존성 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

로컬 웹 서버로 테스트하려면 저장소 루트에서 다음 명령어를 실행하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`에 접속합니다.

## 기능

- 할 일 추가, 완료 체크, 삭제
- 전체 / 진행 중 / 완료 필터링
- 완료율 프로그레스 바
- `localStorage`에 자동 저장 (동일 브라우저에서 새로고침해도 유지)
- 모바일/데스크톱 반응형 레이아웃

## 기술 스택

HTML, CSS, Vanilla JavaScript — 외부 라이브러리 없음.

> 참고: 서버나 데이터베이스는 사용하지 않으며, 할 일 데이터는 사용자의 브라우저에만 저장됩니다.
