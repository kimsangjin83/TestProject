# Block Arena — 변경 이력

제품 기능 이력의 기준은 [ROADMAP.md](../ROADMAP.md)와 [GitHub Issues](https://github.com/kimsangjin83/TestProject/issues)다. 여기에는 사용자에게 의미 있는 변경을 요약한다.

## 2026-10-23 (문서/프로세스 준비)
- ChatGPT/Codex 병행 개발을 위한 `AGENTS.md` 및 AI 협업·아키텍처·개발·배포 문서 초안 작성.
- 역할, 브랜치 충돌 방지, 사용자 승인 기반 운영 배포 및 보안 원칙 문서화.
- **기능 구현이나 AWS 배포가 완료된 것은 아니다.**

## v0.2 — 2026-10-22 기준 운영
- 메인/싱글/멀티/기록/설정 메뉴 및 화면 전환.
- 모바일 가로 회전 안내, 기존 싱글 플레이/PWA 개선.
- 멀티플레이는 UI 단계이며 서버 연결 없음.

## v0.1 — 초기 프로토타입
- 싱글 플레이, 모바일 UI, 설치형 PWA, 줄 제거 애니메이션 기반 구축.

추후 릴리스 일자와 상세 변경 사항은 실제 main 병합 및 배포 결과 확인 후 기록한다.
